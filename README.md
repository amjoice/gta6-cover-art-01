**Neon Shore Cover Studio** is a GTA-style cover art maker, built for the [make.fun GTA 6 cover art bounty](https://make.fun/bounty/gta6-cover-art-01). Pick from 6 cover layouts and 5 colour grades, place the Anton and Pacifico artwork, and export the cover as a PNG in 3 sizes.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network requests, just static files under `app/`.
